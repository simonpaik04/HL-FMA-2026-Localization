# 홍익대 현 위치 평행주차 테스트 RDDF

2026-09-18 차량을 직진시켜 측정한 GPS `37.5512383, 126.9251911`을 진입 첫 점으로 사용한다.
직진 전 기준점 `37.5511579, 126.9251536`에서 측정한 이동거리는 `9.532 m`이다.
기존 홍익대 map 원점 `37.5511496, 126.9250846`은 전체 미션 경로와의 호환성을 위해 유지한다.
RViz 수동 초기화에서 확인한 차량 yaw `-0.3328087318 rad`에 맞춰 홍익대 전체 RDDF와
미션 마커를 동일한 강체 변환으로 이동·회전했다. 모든 경로의 거리와 기어 전환 지점은 유지한다.

2026-09-18 9번 구간 직진 측정(7.195 m)에서 실제 이동 방향은 `1.0865708854 rad`
(`62.255926 deg`)였다. 9번 RDDF 직선 방향 `1.6536957612 rad`과 평행하도록
초기화 기준점 `(14.850640, 1.242240)`을 고정하고 전체 RDDF와 미션 마커를
`-0.5671248758 rad` (`-32.493862 deg`) 강체 회전했다.

새 디렉터리 안의 19개 경로는 모두 새 좌표계로 교체했으며, 변환 전 좌표의 경로는 섞이지 않는다.

진입 경로 `10_parallel-left-in`은 reverse 방향 경로이므로 첫 경로 접선 yaw는
`2.8087839218 rad`이며 차량 yaw는 그 반대인 `-0.3328087318 rad`이다.

실행:

```bash
./run.sh hongik_parallel_test:=true enable_lidar:=false enable_camera:=false \
  start_object_detection:=false start_local_planner:=false \
  start_traffic_light:=false arduino_port:=/dev/ttyUSB1
```
