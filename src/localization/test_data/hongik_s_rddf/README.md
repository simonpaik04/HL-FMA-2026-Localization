# 홍익대 S구간 시작 테스트 RDDF

기존 홍익대 RDDF 전체를 동일한 강체 변환으로 이동·회전한 별도 사본이다.
S구간 `3_s-static-obstacle`의 첫 점 위치는 유지하고 GPS 직진 방향에 맞췄다.
GPS 출발: 37.5514945, 126.9249636 (1789648658.1095645).
GPS 도착: 37.5516177, 126.9250098 (1789648696.70736852).
GPS 이동거리: 14.270 m. 아래 yaw는 GPS 변위 기준이다.
관측 토픽: /molit/localization/odometry, ROS 시각: 1789647374.8962998.
시작 map 좌표: (-10.940063988843454, 38.013119283926656) m, yaw: 1.2806584092575455 rad.
기존 S 시작점 기준 회전: 95.45426933937381 deg.
map 원점은 기존 홍익대와 동일: 37.5511496, 126.9250846.
전체 CSV, 경로 편집 JSON, 미션 마커를 함께 변환했다. 구간별 거리와 분기는 유지한다.

실행: `./run.sh hongik_s_test:=true`
초기 위치는 Localization RViz에서 3_s-static-obstacle 시작점을 선택한다.
실행 옵션은 State Manager, route provider, Localization, LiDAR ROI에 같은 맵을 적용한다.
기존 홍익대/용인 파일은 변경하지 않는다. 이 파일은 운동장 경계에 맞춰 새로 설계한 경로는 아니다.
