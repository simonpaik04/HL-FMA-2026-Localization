# 홍익대 운동장 위치 이동 테스트 RDDF

2026-09-17 GPS 관측 좌표: 37.5511496, 126.9250846.
관측 상태: 3D_FIX, fix_ok=true, RTK FIXED 아님. 수평 정확도 약 0.48m.
1_left 첫 점을 위 좌표 및 map (0, 0)으로 옮겼다.
전체 경로·미션 마커를 동일하게 평행이동한 뒤 실측 GPS 직진 궤적에 맞춰 회전했다.
2026-09-17 직진 표본(ROS 시각 1789641945~1789641961)의 직선 적합 방향은 동쪽 기준 반시계 68.929831도다.
기존 경로에서 시계방향 92.666850도 회전했으며 시작 좌표, 거리, 분기, 곡률은 유지했다.
파일명은 기존 로더 호환을 위해 yongin 접두어를 유지한다.

기존 용인 RDDF는 변경하지 않았다. 운동장 경계에 맞춰 설계한 경로가 아니다.
전체 실행에 hongik_test:=true를 주면 이 사본과 전용 초기화·뷰어·미션 설정을 사용한다.
적용 시 route provider, 초기화, tracker, viewer의 RDDF 디렉터리를 모두 이 사본으로 맞추고,
초기화 reference의 latitude_deg=37.5511496, longitude_deg=126.9250846으로 맞춰야 한다.
좌표는 GPS 안테나 관측점이며 base_link 오프셋 보정은 적용하지 않았다.
